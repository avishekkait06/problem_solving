# Problem Solving

A personal collection of **programming problem solutions** from various competitive programming platforms, online judges, and contests.

This repository contains solutions created while practicing **Data Structures, Algorithms, problem solving, competitive programming, and programming contests**.

## Platforms & Contests

* [HackerRank](https://www.hackerrank.com/)
* [CodeChef](https://www.codechef.com/)
* [VJudge](https://vjudge.net/)
* [AtCoder](https://atcoder.jp/)
* [CSES](https://cses.fi/)
* [LightOJ](https://lightoj.com/)
* Other online judges and competitive programming contests

## Purpose

The main goals of this repository are to:

* Practice competitive programming and problem solving
* Improve Data Structures and Algorithms skills
* Maintain a personal archive of solved problems
* Practice problems from different platforms and contests
* Track progress and improve problem-solving skills
* Revisit previously solved problems and explore better approaches

These solutions are primarily maintained for **learning, practice, and reference purposes**.
